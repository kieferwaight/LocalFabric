# Example Project

Tiny dummy README used as a markdown-runtime test fixture. Exercises
header detection, list extraction, fenced code parsing, and inline emphasis.

## Highlights

- Lightweight, no dependencies
- Reads from a single config file
- Emits structured logs

## Quickstart

```bash
example --config config.json --verbose
```

> Note: do not point this at a production endpoint.
