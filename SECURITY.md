# Security Policy

## Reporting a Vulnerability

If you believe you've found a security issue in LocalFabric, please report it privately via [GitHub Security Advisories](https://github.com/kieferwaight/LocalFabric/security/advisories/new).

Please do **not** open a public issue for security reports.

We'll respond within a reasonable timeframe and coordinate a fix and disclosure.

## Supported Versions

Only `main` is supported. There are no tagged releases yet; pin to a commit if you need stability.
